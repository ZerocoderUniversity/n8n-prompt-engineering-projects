# PEn03. Поток данных между нодами

## Зачем этот проект

Проект показывает базовую механику n8n: одна нода создаёт данные, следующая получает их и формирует результат. Это фундамент для всех последующих сценариев с API, ветвлениями и ИИ.

## Что делает workflow

1. Запускается вручную.
2. Создаёт тестовые данные студента.
3. Передаёт их в Code-ноду.
4. Собирает персонализированное приветствие.

## Что изучаем

- структуру item и JSON в n8n;
- передачу данных между нодами;
- настройку полей через Edit Fields/Set;
- обращение к входным данным в Code-ноде;
- чтение результата выполнения каждой ноды.

## Файлы

- `workflow.json` — готовый демонстрационный workflow.

## Запуск

Импортируйте `workflow.json` в n8n и нажмите **Execute Workflow**. Credentials и внешние сервисы не нужны.

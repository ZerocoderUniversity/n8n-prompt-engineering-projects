## Как запустить workflow

1. Откройте n8n.
2. Создайте новый workflow и выберите **Import from File**.
3. Импортируйте нужный JSON-файл из папки урока.
4. Изучите README урока и настройте Credentials, URL и идентификаторы сервисов.
5. Сначала запустите сценарий вручную на тестовых данных.
6. Активируйте production-триггеры только после проверки всех веток, включая ошибки.

## Требования

- актуальная версия n8n;
- для уроков 05–08 — доступы к указанным внешним сервисам;
- тестовое окружение или тестовые записи в CRM/базе;
- понимание правил обработки персональных данных для выбранной инфраструктуры.

## Безопасность

- Не храните API-ключи, пароли и webhook-токены в JSON-файлах или Git.
- Создавайте секреты через раздел **Credentials** в n8n.
- Ссылки на локальные Credentials удалены из экспортов; после импорта привяжите собственные подключения.
- Проверяйте импортированный workflow до активации.
- Для CRM-сценариев начинайте с тестовой воронки и тестовых лидов.
- Оставляйте человеку подтверждение необратимых действий: отправки клиенту, отказа, удаления или смены стадии.

## Структура

В каждой папке урока есть README с назначением проекта, схемой работы и шагами настройки. Файл `workflow.json` или нумерованные JSON-файлы можно импортировать непосредственно в n8n. Презентации уроков лежат в подпапке `materials/`.

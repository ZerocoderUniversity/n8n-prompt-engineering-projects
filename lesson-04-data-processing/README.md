# PEn04. Обработка данных в n8n

## Зачем эти проекты

Набор из шести небольших workflow тренирует основные операции, из которых собираются реальные автоматизации: преобразование, очистку, маршрутизацию, работу с массивами и устойчивость к ошибкам.

## Проекты

| Файл | Что делает | Навык |
| --- | --- | --- |
| `01-data-transformation.json` | Изменяет поля и даты с помощью Edit Fields, Code и Date & Time. | Преобразование данных. |
| `02-cleaning-and-aggregation.json` | Удаляет дубли, сортирует, ограничивает выборку и считает итог. | Очистка и агрегация. |
| `03-if-and-merge-shipments.json` | Разводит отправления по условиям и снова объединяет ветки. | IF и Merge. |
| `04-switch-routing.json` | Направляет записи по городам London, New York, Tokyo и Other. | Многовариантная маршрутизация. |
| `05-arrays-loops-filter.json` | Разворачивает массив клиентов, обрабатывает пакетами, фильтрует и собирает статистику. | Split Out, Loop Over Items, Filter, Switch и Merge. |
| `06-error-handling-demo.json` | Имитирует ошибку и показывает повторные попытки и Error Output. | Контролируемая обработка сбоев. |
| `clients-example.json` | Содержит учебный набор клиентов. | Практика со структурами данных. |

## Как проходить

Импортируйте workflow по порядку от 01 до 06. Все проекты запускаются вручную и используют тестовые данные, поэтому Credentials не требуются. После каждой ноды сравнивайте входной и выходной JSON.

Для проекта 05 проверьте, что после Split Out получилось 8 items, цикл обрабатывает их пакетами по 2, а записи без телефона попадают в `skipped`. Для проекта 06 проследите, как тестовая ошибка после повторных попыток уходит в отдельный выход.
